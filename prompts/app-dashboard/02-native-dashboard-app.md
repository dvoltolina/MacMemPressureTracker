# 02-native-dashboard-app.md

## Task

Add a native macOS dashboard app and app icon.

## Context

The monitor currently runs as a CLI-installed launchd job. The user wants a tiny dashboard and icon
so it can be opened like a normal app.

## Dependencies

Depends on `01-status-helper.md`.

## Implementation Notes

- Build with `/usr/bin/swiftc` and AppKit; do not introduce third-party dependencies.
- Build output should be `build/Memory Pressure Monitor.app`.
- The app should be path-bound to the current repo root via `Info.plist`, matching existing
  launchd behavior.
- Dashboard should include:
  - status text from `scripts/status.sh`
  - Refresh
  - Install / Reload
  - Uninstall
  - Test Notification
  - Open Log
- Commands must run repo-local scripts with fixed arguments.
- Icon can be deterministic code-native artwork generated by Swift into `.icns`; do not require AI
  image generation for the simple icon.
